# 彩画起谱坊 · 官式建筑彩画起谱与贴金预览系统

浏览器内运行的官式（和玺 / 旋子 / 苏式）建筑彩画参数化起谱、青绿配色校验、沥粉贴金 PBR 三维预览与足尺分页出图工具。
技术栈：**TypeScript + React + Three.js + Canvas2D + IndexedDB + Vitest**，无需后端。

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # 21 项规则/配色/分页单测
npm run build      # 类型检查 + 生产构建到 dist/
```

首次打开会自动写入一座**五开间正殿测试项目：42 个构件，其中梁 6、枋 21（梁枋合计 27 根）、檩 5、垫板 10**，并含一根故意过短的“短穿插枋”用于演示尺度预警。

## 最关键：起谱规则（`src/caihua/rules.ts`，纯函数、确定性）

所有尺寸内部统一为毫米。

1. **分三停**：默认 `fangxinRatio = 1/3`，枋心居中占一停，左右停严格等长 `(L − L/3)/2 = L/3`。任何长度（含 0、NaN、极长/极短）都不抛异常，区域左右镜像。
2. **箍头 / 盒子**：箍头宽按面高比例并受“最多占一停比例”约束，超限给出 `gutou-clamped` 提示；盒子为方形，`auto` 模式按找头份数阈值决定是否设置，留盒后放不下会自动取消并提示。
3. **旋花路数**：以找头净高得到理想旋花径 `d₀` 与允许区间 `[dMin,dMax]`，令半径 `u=d/2` 为一“份”，找头长 `Z = m·u`。在所有整数 `m` 中选旋花径最接近 `d₀` 且落在则例区间者，映射到传统谱式：
   - `m=1` 勾丝咬，`m=2` 喜相逢，`m=3` 喜相逢加一路；
   - `m=4` 一整两破；`m=4+k` 一整两破加 k 路；更大长度转为“N 整两破加 k 路”。
   - 找头越长，`m`/路数**单调不减**（有扫描测试保证）。
4. **尺度提示**：短到连最小“勾丝咬”（约 `0.5·dMin`）都放不下时返回 `zhaotou-too-short`（error），整根构件一停内放不下“箍头+最小旋花”时返回 `member-too-short`（error）。UI 顶部角标、工作台警示卡、构件列表都能看到。
5. **确定性**：布局只取决于输入尺寸与 `RuleParams`，不使用 `Date.now/Math.random`；对关键几何/谱式计算 16 位 `fingerprint`。同一参数两次计算 `JSON` 完全相等，浏览器整页刷新后指纹不变（已实测）。

> 不同流派/口传的比例与路数口径会有差异，因此所有关键系数都在“设置 → 则例与模数”中可调，调整后全项目即时重算。

## 青绿相间与相邻错开（`src/caihua/colors.ts`）

- 以枋心为 ring 0，向外逐环交替青/绿；环号按“是否设盒子”压缩，保证**实际相邻色区一定异色**且左右镜像。
- 构件奇偶优先由网格 `bay + course + line位` 推导：同 run 相邻开间、同轴线同开间上下皮（枋—垫板—檩）自动错开；横向梁架按缝号交替。
- 手改任一色区后，`checkColorRules(project)` 同时检查“单根相邻色区撞色”和“相邻构件基调撞色”，输出带构件名的违规；颜色面板可逐区改回自动，或用 `arrangeColors()` 在相邻关系图上做二分染色并显式写回每根构件，做到一键重排、刷新不变。测试殿默认配色 **0 违规**。

## 贴金 / 沥粉的三维做法（`src/caihua/painter.ts` + `draftPaint.ts` + `three/HallScene.ts`）

同一套纹样绘制输出 5 个通道：`beauty`（青绿+金渐变）、`line`（墨线谱）、`metal`（金部白）、`rough`（按金箔粗糙度）、`bump`（沥粉线加粗变白）。
三维中每根构件用同一布局生成 `map / metalnessMap / roughnessMap / bumpMap`：

- `metalness=1` 乘金属度贴图，只有贴金部位是金属；
- 库金 / 赤金 / 银箔各有颜色、粗糙度与环境反射强度，可按部位分别指定；
- 沥粉线进 bumpMap 产生凸起，自定义“暗穹顶 + HDR 反光板”环境给金箔提供随视角移动的高光，配合日照/门窗光，不同角度反光不同；
- 圆檩把顺长的谱子旋转贴到圆柱 V 向，周向留出非彩绘弧。

## 足尺谱子与打印（`src/caihua/tiles.ts` + `components/PrintRoot.tsx`）

按真实毫米 1:1 与所选 A4/A3/A2/A1 纸张、页边距、搭接量做瓦片分页，末页自动贴齐构件末端；每页带裁切线、十字/文字拼接标记（◀接 N / 接 N ▶、上下排）、构件名编号、`当前页/总页 · 1:1` 标题栏。可选“墨线谱+青/绿/金色标”或“彩色效果”，150/200/300 dpi。打印样式只输出 `#print-root`，在系统打印框选“实际大小/100%、不缩放”即可拼出足尺大样。也可逐根导出高清彩图/墨线 PNG。

## 存储与打包

- IndexedDB 库 `caihua-studio-db`：stores `projects / patterns / kv`。

## 说明

纹样为程序化、程式化表达（旋花、团花、卡子、龙草、包袱锦等），用于起谱构图、比例校验、配色与贴金效果预览，并非文物实测高清纹饰；具体工程做法请以设计定案与传世则例为准，比例参数可在设置中按流派调整。
